# FPS Boost

A performance optimizer for Geometry Dash. Every feature is a toggle, so turn on only what you want.

**Frame rate**
- **Unlock FPS**: raises the frame-rate target above 60. Set **Target FPS** to your screen's refresh rate (90 / 120 / 144).

**Reduce GPU load (inside levels)**
- **Disable particles**: skips drawing particle effects.
- **Hide motion trails**: skips drawing streak trails.
- **Hide background**: removes the full-screen background draw (it turns black).

Open the settings from **Mods → FPS Boost**, or with the **FPS Boost** button on the pause screen.

**Good to know:** Geometry Dash already draws with the GPU on Android. This mod does not change that. It raises the frame cap and removes drawing work so the GPU has less to do.
